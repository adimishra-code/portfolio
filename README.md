# Portfolio

My personal portfolio — a GitHub-styled developer site built with React.

**Live:** coming soon

## Features

- Terminal boot intro animation
- GitHub-profile layout: README card, contribution graph, pinned repo cards
- Project cards with demo videos that flip to reveal the tech stack
- Education timeline styled as `git log`
- Contact form powered by Formspree
- Fully responsive, framer-motion animations throughout

## Tech

React · Vite · Framer Motion · CSS (GitHub dark theme)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`.
